# AgCNER data

The raw AgCNER train/dev/test splits are intentionally not redistributed in this repository.

Please obtain the data from the original AgCNER release:

- Repository: https://github.com/guojson/AgCNER
- Dataset paper: https://doi.org/10.1038/s41597-024-03578-5

Place `train2.txt`, `dev2.txt`, `test2.txt` and `label.txt` in this directory before running the experiment scripts. Please follow the terms of the original data release.
