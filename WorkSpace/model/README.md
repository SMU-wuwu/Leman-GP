# Encoder and tokenizer assets

The tokenizer assets in this directory are retained for reference. Pretrained encoder weights and the encoder `config.json` are not redistributed in this public repository.

The experiments use the ERNIE 3.0 encoder configuration described in the manuscript (hidden size 1024, 18 layers, 16 attention heads). Prepare the pretrained encoder weights and configuration according to the manuscript, then place them in this directory or update the path in the relevant experiment configuration.
