## 模型与训练设置

恢复并保持父包的模型参数、初始化、残差连接和标准 Global Pointer multilabel categorical cross-entropy。
学习率保持 ERNIE `3e-5`、其他参数 `1e-4`。双卡、40轮、每5轮快照、最优权重和完整断点恢复机制保留。
未加入另一 agent 的 LayerNorm、Xavier 初始化、分数硬截断或异常 loss 置零。

另一 agent 的改动已在本地 `repairs/a100_step0_fix1/other_agent_snapshot/` 留档。
其中两处问题已用独立最小算例确认：

- 正例 logit=-80 时，标准损失为80、梯度为-1；截断后损失为50、梯度为0。
- 把异常 loss 换为独立的0张量会断开模型计算图，不能作为正常训练处理。

## 实际修复

1. ERNIE 保留 BF16 投影，SDPA 固定 math 后端，以 FP32 中间量计算 attention。
2. 在自定义层投影之前关闭 autocast；字符池化、Adapter、GRU、Manhattan attention、GP及损失统一采用FP32。
3. 关闭低精度 GEMM 归约；主参数仍为FP32，仍允许TF32。
4. 梯度范数以FP64归约，两卡均检查通过后执行裁剪和优化器更新。
5. 数值异常时保留原始梯度，记录每个rank的诊断JSON，两卡共同停止。
6. 显存自动选批量新增有限性检查；数值异常不作为“该批量不适合显存”的理由跳过。

数学结构和损失公式不变；精度与后端变化可能改变浮点结果、显存峰值、自动选出的批量以及速度。
