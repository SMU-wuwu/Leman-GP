# 新权重候选融合：向95%测试集Micro F1推进

本包使用已有权重，不执行新的神经训练。它将历史定稿2的12路候选与统一F/seed42的C阶段、B阶段以及已完成的no_lexicon最佳权重进行融合比较。

三路新来源的选择依据来自开发集已有预测：C阶段原始预测补回旧候选集合遗漏的58个真实实体；在旧集合与C阶段预测之外，B阶段还补回22个，no_lexicon还补回31个。B阶段的best实际上继承A阶段入口权重，不能当作另一个独立随机种子。no_lexicon来自F42父模型的短周期适应，也不是独立从头训练。

## 工作流程

1. `infer.py --preflight`严格检查权重SHA256、词表身份、模型参数与开发集缓存，不占用GPU。
2. `coordinate.py`创建带本轮身份的STOP文件，等待原消融在优化器步骤结束后保存完整状态、释放队列锁和GPU。
3. `infer.py --split dev`生成三路BF16开发集候选，范围固定为GP原始分数大于−32（当前GP输出乘8）。推理前清除batch标签，仅在预测完成后独立计分核对。
4. `select_fusion.py`比较3个来源组合×3个HGB容量×2种阈值拟合方式，共18个方案。外层两个文本哈希分组折固定；每个外层验证折的标签不参与模型或阈值拟合。nested模式在训练折内部三折生成折外分数拟合阈值，self模式使用训练折模型的训练内分数拟合阈值，二者均由外层验证比较。
5. 选择开发集外层Micro F1最高者，提升不足0.03个百分点则跳过测试；否则固定唯一入选方案，保存模型、阈值、源码身份与`SELECTED_FREEZE.json`。
6. 仅对入选新来源生成测试候选，再用`test.py`执行固定方案的CPU融合计分。
7. 核对消融断点未改变，移除本轮STOP，恢复原队列。恢复不新增训练任务，不修改原配置、源码或随机数状态。

选择采用外层交叉验证，不是训练内开发集分数。基础神经权重历史上已使用开发集选模，这里是后处理验证而非整个系统的独立验证。测试集此前汇总结果已知，后续评价需称同一基准上的再次评估，不称全新留出测试。
